# Qlayo Core 简明使用指南

用桌面 Chrome 或 Edge 打开工作台。源码启动方法见 [项目首页](../README.md)。

## 1. 新建项目并标定底图

打开「新建项目」，填写项目名称和可识别的地点，也可以输入经纬度。「导入底图」支持 PNG、JPG、WebP 和单页 PDF。导入后在图上标出一段已知距离的两端，填写实际长度，再设置北向并完成标定。手头没有图纸时选「无底图」，直接在米制网格上绘制。

## 2. 绘制屋面和障碍

在「区域 → 新建」选屋面或车棚类型。矩形先点一条边的两个端点，再点第三点定宽。平屋面、双坡和连坡可以用多边形，沿轮廓逐点点击，最后点对勾确认。

- 连坡屋面可在左侧快速等分，也可点击「图上切割」添加或拖动分跨线，再设置各跨坡度。
- 选中屋面后可添加附属建筑、障碍物和禁布区。只用来模拟邻栋遮挡的建筑，可从「新建 → 更多」选择「障碍建筑」。
- 底图上的边是斜的，可用「旋转画布 → 图上标定水平」沿参考边点两点。点击右下指北针可恢复正北。

## 3. 布置组件并查看结果

选中屋面，切到「布置」。选组件型号，设置朝向、倾角、连排数量和间距，再点击「布置」。多屋面项目可点「布置全部屋面」。

「更多布置设置」可为当前屋面调整四周间距。双坡和连坡还可设「屋脊间距」，单坡可设「高侧间距」。未单独设置的间距沿用全局默认值。修改屋面、障碍或排布参数后，点击「更新布置」再查看结果。

切到 3D 后，可在「日照与阴影」切换时刻或查看冬至校核。右下角显示装机量和组件数量。

## 4. 保存、导出和实景匹配

- **继续编辑**：点左侧「保存」，将项目保存为 JSON。下次从首页「打开项目」选这个文件。最近项目保存在当前浏览器里。
- **导出布置图**：切到要导出的 2D 或 3D，点工具栏「下载图片」，选择当前区域或全部区域。2D 可选择是否带底图和区域标签。
- **查看报告**：点左侧「报告」，查看总计和区域明细，可打印或另存为 PDF。
- **叠加实景照片**：完成布置后，从工具栏打开「实景匹配」。选对应屋面并导入照片，按编号标注屋面角点或自定义对应点。需要遮住被前景挡住的组件时，圈出前景遮挡区域。点「开始渲染」，预览满意后下载 PNG。
